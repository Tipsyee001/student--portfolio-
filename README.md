# Obanla Temitope Samuel - Student Portfolio

Responsive multi-page portfolio and academic planner built with HTML, CSS and JavaScript (COS 106 term project).

Pages: Home, About Me, Projects, Academic Planner, Contact.

All files sit together in one folder (no sub-folders). To run locally, open `index.html` in a browser.

To use a real photo, replace `image.jpg` with a portrait (4:5 shape works best) keeping the same file name.
